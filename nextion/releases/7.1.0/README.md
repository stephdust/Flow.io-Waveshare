## Changes

- Fresh full-width dark navy background on `pageHome` with a **real Flow.io wave emblem** (taken from `data/webinterface/logo-flowio.png`), lowercase `flow.io`, and a red swimming-pool thermometer icon.
- Two rainbow semicircular pH/ORP gauges with **no bordered capsules around their reference numbers**. `7.5` and `700` remain nominal reference marks, not live readings; dynamic values still come from `tpH.txt` and `tORP.txt`.
- 5-state gauge sprites preserve the original `vapHPercent` / `vaOrpPercent` quantization and use the same picture index `HomeGaugepic=3`.
- Updated 5-state filtration/PSI icon graphics, preserving picture indices 20…24.
- Retain all serial object names, component IDs, touch actions, navigation, RTC update timer, and 7.0.0 version as a stable fallback.
- `pageHome` post-initialize forces the two previous-percentage caches to -1 then refreshes gauges after drawing the backdrop, so graphics should not disappear following wake/reenter. **Hardware validation still required.**
- Retain the live Wi-Fi icon; its color reacts to connection state, **not** to measured RSSI. Static mockup intensity bands are not yet a real RSSI meter.

## Important constraints

This version uses a picture **atlas**: the existing picture #3 has the 5 gauge states at y=0…149 and the 480×320 Home backdrop at y=150…469, allowing the existing picture references and touch components to remain unchanged. The `pageHome` post-initialize event paints the backdrop and redraws all live widgets. The image journal and page are appended with corrected primary and mirrored directory CRCs. The nine page CRCs, image geometry, and file bounds are checked by the builder.

**Do not change `platformio.ini` or publish a `.tft` until the new `.HMI` opens and compiles in Nextion Editor, and is verified on the real screen.** A passing structural CRC check is not sufficient to guarantee that the editor accepts the changed image resource and event scripts. If Nextion Editor reports damage or compiler errors, do not flash; use the known-good 7.0.0 source and report the exact error.
